# 📌 Project Overview

This repository contains an end-to-end Microsoft Excel Data Analytics project designed to demonstrate practical skills in data cleaning, transformation, analysis, visualization, and dashboard development.

The project simulates a real-world business dataset and showcases how raw data can be converted into meaningful insights using Microsoft Excel.

This portfolio project highlights the complete analytics workflow—from importing raw data to creating interactive dashboards that support data-driven decision-making.

---

# 🎯 Project Objectives

The main objectives of this project are to:

* Clean messy and inconsistent data
* Remove duplicates and errors
* Standardize data formats
* Handle missing values
* Organize raw datasets
* Perform descriptive data analysis
* Build Pivot Tables
* Create Pivot Charts
* Develop an interactive dashboard
* Generate business insights
* Present data in a professional format

# 🧹 Data Cleaning Process

The following data cleaning steps were performed:

* Removed duplicate records
* Fixed spelling inconsistencies
* Standardized text formatting
* Converted date formats
* Corrected data types
* Removed blank rows
* Filled missing values
* Removed unnecessary spaces using TRIM
* Applied PROPER, UPPER and LOWER functions
* Checked data integrity
* Validated data entries
* Removed invalid records
